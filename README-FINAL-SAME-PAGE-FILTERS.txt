Τελικό αίτημα:
- Στην αρχική HydroTechnic τα φίλτρα Μπάνια / Υδραυλικά / Θέρμανση / Ηλιακοί δουλεύουν στην ίδια σελίδα.
- Στην αρχική BRK τα φίλτρα Μπάνια / Ανακαινίσεις / Κατασκευές / Βαψίματα δουλεύουν στην ίδια σελίδα.
- Το κουμπί Όλα τα έργα στα φίλτρα δείχνει όλα τα έργα στην ίδια σελίδα.
- Το link Πλήρης σελίδα έργων ανοίγει την archive page.
- Στις archive pages τα έργα είναι 4 ανά σειρά σε desktop.
- Οι φωτογραφίες δεν τεντώνουν.
- Το CSS/JS είναι scoped σε fp-* classes για να μη χαλάει το υπόλοιπο site.

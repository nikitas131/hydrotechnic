# HydroTechnic & BRK Construction

Έτοιμο static site για ανέβασμα σε GitHub Pages, Cloudflare Pages ή Netlify.

## Βασικά αρχεία

- `index.html` — HydroTechnic αρχική
- `hydrotechnic-projects.html` — HydroTechnic έργα
- `brk.html` — BRK Construction αρχική
- `brk-projects.html` — BRK Construction έργα
- `styles.css` — όλο το styling
- `script.js` — ελαφριά γενικά effects
- `projects-clean.js` — φίλτρα και slides έργων
- `burger-menu.js` — mobile burger menu
